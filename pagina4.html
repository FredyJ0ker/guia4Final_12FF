  • Dominio:

    Un nombre de dominio (a menudo denominado simplemente dominio) es un nombre fácil de recordar asociado a una dirección IP física de Internet.

  • Sub dominio:

    dirección única que identifica una página web o un recurso en Internet.

  • URL:

    es una extensión del dominio principal que permite crear subsecciones dentro de un sitio web.

  • DNS:

    "Domain Name System" (Sistema de Nombres de Dominio), es como la guía telefónica de Internet.

  • Hosting:

    " es un servicio que permite almacenar y publicar los archivos de un sitio web en Internet.

  • FTP:

    " es un protocolo de red que permite la transferencia de archivos entre sistemas en una red, especialmente Internet.

  • HTTP:

    "es un protocolo de comunicación utilizado para la transferencia de datos en la web.

  • HTTPS:

    "Hypertext Transfer Protocol Secure", es la versión segura del protocolo HTTP, que es utilizado para la comunicación entre navegadores y sitios web.

  • W3C:

    World Wide Web Consortium, es una organización internacional que desarrolla estándares web para la World Wide Web.

  • UTF-8:

    estándar de codificación de caracteres que permite representar casi cualquier caracter del mundo, incluyendo letras, números, símbolos y caracteres especiales de diferentes idiomas.

  • HTML-5 y estructura:

    es la última versión del Lenguaje de Marcado de Hipertexto (HTML), que se utiliza para estructurar y presentar contenido en páginas web.
